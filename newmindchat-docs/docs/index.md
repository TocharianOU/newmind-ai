## 关于 NewmindChat

NewmindChat 是一款将 AI 对话能力带到本地环境的桌面应用程序。

* **AI 驱动**：先进的 AI 模型支持自然对话
* **MCP 集成**：连接各种 MCP 服务器扩展功能
* **Hub 市场**：访问预配置的模型和工具
* **注重隐私**：本地部署，可选云功能
* **跨平台**：支持 macOS、Windows 和 Linux
