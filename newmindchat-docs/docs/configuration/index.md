# 配置

配置 NewmindChat 以满足您的需求。

## 配置文件

位于 `~/.newmind/config/`：

- `mcp_config.json`：MCP 服务器
- `model_config.json`：AI 模型
- `plugin_config.json`：插件

## 配置主题

- [MCP 配置](mcp-config.md)
- [模型配置](model-config.md)
- [应用设置](settings.md)

## 编辑配置

1. 使用设置 UI（推荐）
2. 或直接编辑 JSON 文件

## 备份
