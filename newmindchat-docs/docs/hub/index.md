# NewmindChat Hub

Hub 是连接 NewmindChat 与云服务的中心平台，提供对预配置 AI 模型和 MCP 服务器的访问。

## 什么是 Hub？

NewmindChat Hub 提供：

- **预配置的 AI 模型**：无需 API 密钥设置即可访问 GPT-4、Claude 等模型
- **MCP 服务器市场**：一键发现和安装 MCP 服务器
- **账户管理**：管理订阅和使用情况
- **自动更新**：自动获取最新的服务器配置
- **使用跟踪**：监控您的 API 使用和成本

## 开始使用 Hub

1. **[登录](login.md)**：创建账户或登录
2. **[浏览模型](models.md)**：探索可用的 AI 模型
3. **[尝试 MCP 市场](mcp-marketplace.md)**：安装预配置的服务器
4. **[选择计划](subscription.md)**：选择您的订阅级别
