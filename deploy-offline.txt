离线手动部署指南
服务器 IP: 10.92.200.43  端口: 23000
账号: admin@test.starbucks.cn / starbuckstest123
适用于无外网环境，所有依赖本地上传安装

================================================================
第一步：在有网络的机器上准备安装包（在旧服务器 204.168.178.42 执行）
================================================================

wget https://nodejs.org/dist/v20.19.0/node-v20.19.0-linux-x64.tar.gz
wget https://github.com/astral-sh/uv/releases/latest/download/uv-x86_64-unknown-linux-gnu.tar.gz

传到新机器（在你 Mac 上执行）:
scp root@204.168.178.42:/root/node-v20.19.0-linux-x64.tar.gz root@10.92.200.43:/opt/
scp root@204.168.178.42:/root/uv-x86_64-unknown-linux-gnu.tar.gz root@10.92.200.43:/opt/

打包源代码（在旧服务器执行）:
tar -czf /tmp/newmind-src.tar.gz -C /opt newmind-ai
scp /tmp/newmind-src.tar.gz root@10.92.200.43:/opt/

================================================================
第二步：新机器安装 Node.js 20
================================================================

tar -xzf /opt/node-v20.19.0-linux-x64.tar.gz -C /usr/local/
ln -sf /usr/local/node-v20.19.0-linux-x64/bin/node /usr/local/bin/node
ln -sf /usr/local/node-v20.19.0-linux-x64/bin/npm /usr/local/bin/npm
ln -sf /usr/local/node-v20.19.0-linux-x64/bin/npx /usr/local/bin/npx
node -v

================================================================
第三步：新机器安装 uv
================================================================

tar -xzf /opt/uv-x86_64-unknown-linux-gnu.tar.gz -C /usr/local/bin/
chmod +x /usr/local/bin/uv
uv --version

================================================================
第四步：安装 Python 3.12 和 PostgreSQL（apt 本地源）
================================================================

apt-get update
apt-get install -y python3.12 python3.12-venv git openssl postgresql postgresql-client

================================================================
第五步：初始化 PostgreSQL
================================================================

systemctl start postgresql
systemctl enable postgresql

sudo -u postgres psql << 'SQL'
ALTER USER postgres PASSWORD 'starbuckstest123';
CREATE DATABASE attacktrace;
SQL

================================================================
第六步：解压源代码
================================================================

tar -xzf /opt/newmind-src.tar.gz -C /opt/

================================================================
第七步：写 .env
================================================================

cat > /opt/newmind-ai/AttackTraceHub/.env << EOF
POSTGRES_PASSWORD=starbuckstest123
JWT_SECRET=$(openssl rand -hex 32)
ATTACKTRACE_AUTH_TOKEN=$(openssl rand -hex 32)
ADMIN_EMAIL=admin@test.starbucks.cn
ADMIN_PASSWORD=starbuckstest123
ALLOWED_ORIGINS=http://10.92.200.43:23000
DEPLOYMENT_MODE=enterprise
SSO_ENABLED=false
BILLING_ENABLED=false
INVITE_CODE_ENABLED=false
LICENSE_ENABLED=false
EOF

set -a; source /opt/newmind-ai/AttackTraceHub/.env; set +a

================================================================
第八步：构建主聊天前端 /app/
================================================================

cd /opt/newmind-ai
npm install --ignore-scripts
npx vite build --config vite.config.web.ts
cp -r dist-web AttackTraceHub/app-dist

================================================================
第九步：构建管理后台 /console/
================================================================

cd /opt/newmind-ai/AttackTraceHub/frontend
npm install --ignore-scripts
npx vite build
cp -r dist /opt/newmind-ai/AttackTraceHub/console-dist

================================================================
第十步：Hub 依赖 + 数据库迁移
================================================================

cd /opt/newmind-ai/AttackTraceHub
npm install

DATABASE_URL="postgresql://postgres:starbuckstest123@localhost:5432/attacktrace" \
  npx prisma migrate deploy

================================================================
第十一步：安装 MCP Host Python 依赖
================================================================

cd /opt/newmind-ai/mcp-host
python3.12 -m venv .venv
source .venv/bin/activate
uv sync --frozen
mkdir -p data
echo '[]' > data/plugin_config.json
echo '{}' > data/command_alias.json

================================================================
第十二步：启动 MCP Host
================================================================

set -a; source /opt/newmind-ai/AttackTraceHub/.env; set +a

nohup env \
  ATTACKTRACE_AUTH_TOKEN="${ATTACKTRACE_AUTH_TOKEN}" \
  RESOURCE_DIR=/opt/newmind-ai/mcp-host/data \
  ATTACKTRACE_CONFIG_DIR=/opt/newmind-ai/mcp-host/data \
  DIVE_SERVICE_CONFIG_CONTENT='{"checkpointer":{"uri":"sqlite:////opt/newmind-ai/mcp-host/data/checkpointer.db"}}' \
  /opt/newmind-ai/mcp-host/.venv/bin/attacktrace_httpd \
  --listen 0.0.0.0 --port 61990 \
  > /var/log/mcp-host.log 2>&1 &

sleep 5 && curl -s http://localhost:61990/health

================================================================
第十三步：启动 Hub
================================================================

set -a; source /opt/newmind-ai/AttackTraceHub/.env; set +a

nohup env \
  DATABASE_URL="postgresql://postgres:starbuckstest123@localhost:5432/attacktrace" \
  JWT_SECRET="${JWT_SECRET}" \
  MCP_HOST_URL="http://localhost:61990" \
  MCP_HOST_INTERNAL_TOKEN="${ATTACKTRACE_AUTH_TOKEN}" \
  ADMIN_EMAIL="admin@test.starbucks.cn" \
  ADMIN_PASSWORD="starbuckstest123" \
  ALLOWED_ORIGINS="http://10.92.200.43:23000" \
  DEPLOYMENT_MODE="enterprise" \
  SSO_ENABLED="false" \
  LICENSE_ENABLED="false" \
  NODE_ENV="production" \
  PORT=23000 \
  node src/server.js \
  > /var/log/hub.log 2>&1 &

sleep 8 && curl -s http://localhost:23000/api/health

================================================================
日志 / 停止 / 重启
================================================================

查看日志:
tail -f /var/log/hub.log
tail -f /var/log/mcp-host.log

停止:
pkill -f "node src/server.js"
pkill -f "attacktrace_httpd"

重启（停止后重新执行第十二、十三步）:
pkill -f "node src/server.js"; pkill -f "attacktrace_httpd"
sleep 2
set -a; source /opt/newmind-ai/AttackTraceHub/.env; set +a
然后重新执行第十二步和第十三步的 nohup 命令
