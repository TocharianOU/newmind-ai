# 聊天界面

AttackTrace 提供现代化、直观的聊天界面，专为 AI 对话优化。

## 界面布局

### 主要区域

- **侧边栏**：会话列表、设置、模型选择
- **聊天区域**：对话内容显示
- **输入框**：消息输入和发送
- **工具栏**：快捷操作和工具

### 界面特性

- **响应式设计**：适配不同屏幕尺寸
- **暗色/亮色主题**：支持主题切换
- **可调整布局**：自定义界面布局
- **多窗口支持**：同时打开多个对话

## 主要功能

### 对话管理
- **多会话支持**：同时管理多个对话
- **会话命名**：为对话设置自定义名称
- **会话搜索**：快速查找历史对话
- **会话导出**：导出对话内容

### 消息功能
- **Markdown 渲染**：支持富文本格式
- **代码高亮**：语法高亮的代码块
- **数学公式**：LaTeX 数学公式支持
- **图片显示**：内联图片和图表

### 交互功能
- **流式响应**：实时显示 AI 回复
- **消息编辑**：编辑和重新发送消息
- **消息复制**：快速复制消息内容
- **消息分享**：分享对话内容

## 快捷键

### 基本操作
- **新建对话**: `Cmd/Ctrl + N`
- **切换会话**: `Cmd/Ctrl + Tab`
- **清空对话**: `Cmd/Ctrl + Shift + K`
- **发送消息**: `Enter`
- **换行**: `Shift + Enter`

### 编辑操作
- **撤销**: `Cmd/Ctrl + Z`
- **重做**: `Cmd/Ctrl + Y`
- **全选**: `Cmd/Ctrl + A`
- **复制**: `Cmd/Ctrl + C`
- **粘贴**: `Cmd/Ctrl + V`

### 界面操作
- **切换侧边栏**: `Cmd/Ctrl + B`
- **切换主题**: `Cmd/Ctrl + T`
- **全屏模式**: `F11`
- **开发者工具**: `Cmd/Ctrl + Shift + I`

## 高级功能

### MCP 工具集成
- **工具调用**：AI 可以调用 MCP 工具
- **工具结果**：显示工具执行结果
- **工具历史**：查看工具使用历史

### 模型切换
- **快速切换**：在对话中切换模型
- **模型比较**：同时使用多个模型
- **模型设置**：自定义模型参数

### 对话历史
- **自动保存**：自动保存对话历史
- **历史搜索**：搜索历史对话内容
- **历史同步**：跨设备同步对话

## 自定义设置

### 界面设置
- **字体大小**：调整界面字体大小
- **行间距**：设置文本行间距
- **颜色主题**：选择喜欢的颜色主题
- **布局模式**：选择界面布局模式

### 行为设置
- **自动保存**：设置自动保存间隔
- **消息通知**：配置消息通知设置
- **快捷键**：自定义快捷键
- **语言设置**：选择界面语言

## 故障排除

### 常见问题
- **界面卡顿**：检查系统资源使用
- **消息丢失**：检查网络连接
- **快捷键失效**：检查快捷键冲突
- **主题问题**：重置主题设置

### 性能优化
- **清理缓存**：定期清理应用缓存
- **关闭不必要功能**：禁用不需要的功能
- **更新应用**：保持应用最新版本
- **系统优化**：优化系统性能设置
