# MCP 工具

MCP（模型上下文协议）工具为 AttackTrace 提供了强大的扩展能力，让 AI 能够访问外部数据源和执行特定任务。

## 什么是 MCP？

Model Context Protocol (MCP) 是一个开放标准，允许 AI 应用程序连接到外部工具和数据源。通过 MCP，AI 可以：

- 访问实时数据
- 执行特定操作
- 与外部系统交互
- 扩展 AI 能力

## 工具类型

### 数据查询工具
- **Elasticsearch**：搜索和分析日志数据
- **数据库连接**：查询关系型数据库
- **API 集成**：调用外部 API 服务

### 可视化工具
- **Kibana**：创建和管理数据仪表板
- **图表生成**：自动生成数据可视化
- **报告创建**：生成分析报告

### 开发工具
- **代码执行**：运行代码片段
- **文件操作**：读写文件系统
- **版本控制**：Git 操作和管理

### 自定义工具
- **业务逻辑**：特定业务需求
- **第三方集成**：连接专有系统
- **自动化脚本**：执行重复任务

## 启用 MCP 工具

### 1. 配置 MCP 服务器

在 AttackTrace 设置中启用所需的 MCP 服务器：

1. 打开 **设置** > **MCP 服务器**
2. 启用您需要的服务器
3. 配置连接参数
4. 保存设置

### 2. 验证工具可用性

启用后，您可以在对话中看到可用的工具：

```
显示可用的 MCP 工具
```

### 3. 使用工具

AI 会根据您的请求自动选择合适的工具：

```
搜索过去24小时的错误日志
创建访问量趋势图
分析用户行为数据
```

## 内置工具

### Echo 服务器
- **功能**：测试和验证 MCP 连接
- **用途**：开发调试、功能测试
- **状态**：默认启用

### Kibana 服务器
- **功能**：数据可视化和仪表板管理
- **配置**：需要 Kibana 实例连接
- **用途**：监控、分析、报告

### Elasticsearch 服务器
- **功能**：数据搜索和分析
- **配置**：需要 Elasticsearch 集群连接
- **用途**：日志分析、数据探索

## 工具配置

### 环境变量
每个 MCP 服务器可能需要特定的环境变量：

```bash
# Elasticsearch
ES_URL=https://your-cluster.com:9200
ES_API_KEY=your-api-key

# Kibana
KIBANA_URL=https://your-kibana.com:5601
KIBANA_USERNAME=your-username
KIBANA_PASSWORD=your-password
```

### 权限设置
确保 MCP 服务器有足够的权限：
- 文件系统访问
- 网络连接
- 数据库访问
- API 调用权限
