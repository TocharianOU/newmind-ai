# 登录 Hub

## 什么是 AttackTrace Hub？

AttackTrace Hub 是集中管理平台，提供：

- 预配置的 AI 模型
- MCP 服务器市场
- 账户管理
- 使用量跟踪

## 访问 Hub

**[访问 AttackTrace Hub 登录页面](http://xiaopenges.tocharian.eu:23001/login)**

## 创建账户

1. 访问 [Hub 登录页面](http://xiaopenges.tocharian.eu:23001/login)
2. 点击 **创建新账户** 或 **注册**
3. 填写以下信息：
   - 用户名
   - 邮箱地址
   - 密码（至少 8 个字符）
4. 点击 **注册**
5. 账户创建成功后即可登录

## 登录流程

### 第一次登录

1. 访问 [Hub 登录页面](http://xiaopenges.tocharian.eu:23001/login)
2. 输入您的用户名/邮箱和密码
3. 点击 **登录**
4. 登录成功后，您可以在 Dashboard 查看使用统计

### 后续登录

应用会记住您的登录状态。除非您：

- 手动登出
- 清除了应用数据
- 重新安装了应用

## 账户管理

### 修改个人信息

1. 登录后，点击右上角的用户头像
2. 选择 **账户设置**
3. 可以修改：
   - 显示名称
   - 邮箱地址
   - 密码
   - 头像

### 登出

1. 点击右上角的用户头像
2. 选择 **登出**
3. 本地数据和设置会被保留
4. Hub 同步的模型配置会被移除

## 隐私和安全

### 存储的数据

Hub 会存储：

- 账户信息（邮箱、名称、头像）
- 模型使用统计
- MCP 服务器配置（如果选择同步）
- 订阅信息

Hub **不会**存储：

- 您的对话内容
- API 密钥（仅本地存储）
- 私人文件或数据

### 安全最佳实践

- 使用强密码
- 不要分享您的账户
- 定期更新密码
- 启用两步验证（如果可用）

## 故障排除

### 无法登录

如果遇到登录问题：

1. 检查网络连接
2. 确认邮箱和密码正确
3. 尝试重置密码
4. 检查邮箱是否已验证

### 忘记密码

1. 在登录页面点击 **忘记密码**
2. 输入您的注册邮箱
3. 检查邮箱中的重置链接
4. 设置新密码
5. 使用新密码登录

### 网络代理

如果您在企业网络或使用代理：

1. 进入 **设置** > **网络**
2. 配置代理设置
3. 重新尝试登录
