# Hub 模型

## 概述

AttackTrace Hub 提供自研 AI 模型，无需设置 API 密钥即可使用。

## 可用模型

### newmind-medium（推荐）

高性能推理模型，平衡质量与成本。

**特性**:
- 强大的推理能力
- 支持工具调用和 MCP
- 流式响应
- 大上下文窗口

**定价**: $3.00 输入 / $15.00 输出（每 1M tokens）

**适用场景**: 代码生成、文本分析、日常对话、数据处理

### newmind-strong（企业专属）

旗舰级推理模型，最高质量输出。

**特性**:
- 顶级推理能力
- 最佳输出质量
- 支持工具调用和 MCP
- 流式响应
- 仅限 ENTERPRISE 计划

**定价**: $15.00 输入 / $75.00 输出（每 1M tokens）

**适用场景**: 复杂推理、高精度任务、关键业务决策

### newmind-small

轻量级模型，快速响应低成本。

**特性**:
- 快速响应
- 经济实惠
- 支持工具调用和 MCP
- 适合简单任务

**定价**: $1.00 输入 / $2.00 输出（每 1M tokens）

**适用场景**: 简单对话、代码补全、文本摘要

## 使用 Hub 模型

### 选择模型

1. 确保已[登录 Hub](login.md)
2. 在聊天界面点击模型选择器
3. Hub 模型会显示 **Hub** 标签
4. 选择您想使用的模型

### 模型切换

您可以随时切换模型：

- 在同一个对话中切换
- 不同对话使用不同模型
- 根据任务选择最适合的模型

### 使用限制

根据您的[订阅计划](subscription.md)：

- BASE: 每日 10M tokens
- PRO: 每日 50M tokens  
- ENTERPRISE: 无限 tokens

详见[订阅计划](subscription.md)页面。

## 模型参数

某些 Hub 模型允许调整参数：

### Temperature

- **范围**: 0.0 - 2.0
- **默认**: 0.7
- **低值** (0.0-0.3): 更确定、一致的输出
- **中值** (0.4-0.9): 平衡创造性和一致性
- **高值** (1.0-2.0): 更随机、创造性的输出

### Top P

- **范围**: 0.0 - 1.0
- **默认**: 1.0
- **作用**: 控制采样范围

### Max Tokens

- **作用**: 限制响应长度
- **注意**: 不同模型有不同的最大值

## 使用统计

查看您的模型使用情况：

1. 登录 Hub
2. 点击用户头像 > **使用统计**
3. 查看：
   - 每日使用量
   - 按模型分类的统计
   - 剩余配额
   - 成本明细（如适用）

## 故障排除

### 模型不可用

如果某个模型无法使用：

- 检查您的订阅计划
- 确认您已登录 Hub
- 检查是否达到使用限制
- 查看 Hub 状态页面

### 请求限制

如果遇到限制错误：

- 等待限制重置（通常每小时或每天）
- 考虑升级订阅计划
- 使用自定义 API 密钥

### 性能问题

如果模型响应缓慢：

- 切换到更快的模型
- 减少上下文长度
- 检查网络连接
- 查看 Hub 状态

## 最佳实践

1. **选择合适的模型**: 根据任务复杂度选择
2. **监控使用量**: 避免意外超出限制
3. **优化提示词**: 减少不必要的 token 消耗
4. **混合使用**: Hub 模型和自定义模型结合
