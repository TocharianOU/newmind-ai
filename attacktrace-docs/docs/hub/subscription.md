## 计费详情

### 付款方式

接受以下付款方式：

- 信用卡 / 借记卡
- PayPal
- 电汇（仅企业计划）
- 支付宝（部分地区）
- 微信支付（部分地区）

### 计费周期

**月付**:
- 每月自动续费
- 随时可取消
- 取消后在当前周期结束时生效

**年付**:
- 一次性支付
- 享受折扣（通常 17-20%）
- 更适合长期用户

### 退款政策

**7 天试用保证**:
- 首次订阅后 7 天内
- 无条件全额退款
- 适用于专业计划

**年度订阅**:
- 前 30 天内按比例退款
- 扣除已使用部分

### 发票

- 所有付款自动生成电子发票
- 可在账户中下载
- 企业客户可申请专用发票

## 升级和降级

### 升级计划

从免费升级到专业：
1. 进入 **设置** > **订阅**
2. 选择 **专业计划**
3. 选择付款方式
4. 立即生效

从专业升级到企业：
1. 联系销售团队
2. 讨论需求和定价
3. 签订合同
4. 迁移和配置

### 降级计划

从专业降级到免费：
1. 进入 **设置** > **订阅**
2. 选择 **取消订阅**
3. 当前周期结束后生效
4. 数据保留 30 天

注意事项：
- Hub 模型访问将受限
- MCP 市场服务器可能不可用
- 某些高级功能将禁用

## 常见问题

### 可以随时取消吗？

是的，您可以随时取消订阅。取消后，您可以继续使用直到当前计费周期结束。

### 取消后数据会怎样？

- 本地对话数据保留
- Hub 同步数据保留 30 天
- 30 天后可能被删除
- 可以导出数据（专业/企业用户）

### 如何管理团队成员？

专业计划支持最多 5 个团队成员：
1. 进入 **设置** > **团队**
2. 点击 **邀请成员**
3. 输入邮箱地址
4. 设置权限

### 可以同时使用多个设备吗？

- 免费和专业：最多 3 台设备同时登录
- 企业：无限制

### 如何查看使用量？

1. 登录 Hub
2. 点击用户头像
3. 选择 **使用统计**
4. 查看详细数据
