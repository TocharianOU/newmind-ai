# MCP 服务器

本地 MCP 服务器为 AI 模型提供工具和功能。

## 什么是 MCP 服务器？

实现模型上下文协议的服务器，使 AI 能够访问外部工具和数据。

## 可用服务器

- [Echo 服务器](echo.md)：测试（默认启用）
- [Kibana](kibana.md)：数据可视化
- [Elasticsearch](elasticsearch.md)：搜索和分析
- [自定义服务器](custom.md)：您自己的实现

## 配置

MCP 服务器在 `~/.attacktrace/config/mcp_config.json` 中配置

## 启用/禁用

1. 转到设置 → MCP 服务器
2. 切换服务器开关
3. 如需要则重启应用
