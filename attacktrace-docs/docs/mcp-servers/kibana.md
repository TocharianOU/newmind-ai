# Kibana MCP 服务器

Kibana MCP 服务器允许 AttackTrace 与 Kibana 实例交互，进行数据可视化和仪表板管理。

## 功能特性

- **仪表板管理**：创建、编辑和管理 Kibana 仪表板
- **可视化创建**：生成图表、表格和其他可视化
- **数据探索**：使用 Kibana 的 Discover 功能
- **索引模式**：管理 Elasticsearch 索引模式
- **保存对象**：管理 Kibana 保存的对象

## 配置要求

### 环境变量

```bash
KIBANA_URL=https://your-kibana-instance.com:5601
KIBANA_USERNAME=your-username
KIBANA_PASSWORD=your-password
```

### 认证方式

Kibana 支持多种认证方式：
- **用户名/密码**：基本认证
- **API 密钥**：使用 Elasticsearch API 密钥
- **SAML**：企业单点登录
- **OAuth**：第三方认证

## 使用方法

### 1. 启用服务器

在 AttackTrace 设置中启用 Kibana 服务器，并配置连接参数。

### 2. 数据探索

```
显示过去7天的访问日志
创建访问量趋势图
```

### 3. 仪表板操作

```
列出所有仪表板
创建新的监控仪表板
```

### 4. 可视化创建

```
创建错误率饼图
生成响应时间直方图
```
