# 第一次对话

本指南将引导您使用 AttackTrace 开始第一次 AI 对话。

## 启动应用程序

1. 从应用程序文件夹或开始菜单打开 AttackTrace
2. 等待应用程序初始化（首次启动可能需要 30-60 秒）
3. 您将看到主聊天界面

## 选择 AI 模型

### 选项 1：使用 Hub 模型（推荐初学者）

1. 点击右上角的**登录**
2. 使用您的 Hub 账户登录
3. Hub 模型将自动可用
4. 从下拉菜单选择模型（例如 GPT-4）

### 选项 2：使用自定义 API

1. 点击**设置**图标（⚙️）
2. 转到**模型**部分
3. 点击**添加自定义模型**
4. 输入您的 API 详细信息
5. 点击**保存**
6. 从下拉菜单选择您的模型

## 开始对话

1. 在底部的输入框中输入您的消息
2. 按 **Enter** 或点击**发送**按钮
3. 等待 AI 响应
4. 自然地继续对话

示例第一条消息：
```
你好！你能解释一下什么是 MCP 工具吗？
```

## 使用 MCP 工具

MCP 工具扩展了 AI 的能力。默认情况下，Echo 工具已启用用于测试。

### 尝试 Echo 工具

要求 AI 使用 Echo 工具：

```
你能使用 echo 工具重复"你好 MCP"吗？
```
