# AttackTrace 快速开始

欢迎使用 AttackTrace！本指南将帮助您在几分钟内启动并运行应用程序。

## 前提条件

AttackTrace 在您的桌面上运行，需要：

- **操作系统**：macOS 11+、Windows 10+ 或 Linux（现代发行版）
- **内存**：建议至少 4GB RAM
- **磁盘空间**：500MB 可用空间
- **互联网**：Hub 功能和云模型需要（本地操作可选）

## 快速开始步骤

1. **[下载](download/)** - 获取适合您平台的最新版本
2. **[安装](installation/)** - 按照特定平台的安装说明操作
3. **[第一次对话](first-chat/)** - 开始您的第一次 AI 对话

## 接下来的步骤

完成本指南后，您可以：

- 探索 [Hub 功能](../hub/)获取云模型
- 配置[本地 MCP 服务器](../mcp-servers/)
- 自定义[应用设置](../configuration/)
