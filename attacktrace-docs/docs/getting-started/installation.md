# 安装指南

本指南涵盖所有支持平台的安装程序。

## macOS 安装

### 步骤 1：打开 DMG 文件

1. 在下载文件夹中找到下载的 `.dmg` 文件
2. 双击 DMG 文件挂载它
3. 将打开一个显示 AttackTrace 应用程序的窗口

### 步骤 2：安装应用程序

1. 将 **AttackTrace** 图标拖到 **应用程序**文件夹
2. 等待复制过程完成
3. 右键单击挂载的卷并选择"推出"来推出 DMG

### 步骤 3：首次启动

1. 打开 **访达** → **应用程序**
2. 找到 **AttackTrace** 并双击启动

!!! note "安全警告"
    首次启动时，macOS 可能会显示安全警告。
    
    允许应用运行：
    1. 前往**系统设置** → **隐私与安全性**
    2. 向下滚动找到"AttackTrace 被阻止"
    3. 点击**仍要打开**
    4. 再次启动应用

## Windows 安装

### 步骤 1：运行安装程序

1. 找到下载的 `.exe` 文件
2. 双击启动安装向导
3. 如果出现 Windows SmartScreen，点击**更多信息** → **仍要运行**

### 步骤 2：安装选项

1. 选择安装位置（建议使用默认）
2. 选择是否创建桌面快捷方式
3. 点击**安装**开始

## Linux 安装

### 步骤 1：使 AppImage 可执行

```bash
cd ~/Downloads
chmod +x AttackTrace-*.AppImage
```

### 步骤 2：运行应用程序

```bash
./AttackTrace-*.AppImage
```
