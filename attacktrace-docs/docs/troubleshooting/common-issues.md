# 常见问题

常见问题的解决方案。

## 应用无法启动

**症状**：应用程序无法启动

**解决方案**：
1. 检查系统要求
2. 验证安装
3. 检查[日志](logs.md)
4. 尝试重新安装

## 加载屏幕

**症状**：应用卡在加载转圈

**解决方案**：
1. 等待 2-3 分钟（首次启动较慢）
2. 检查互联网连接
3. 检查防火墙设置
4. 清除缓存：`rm -rf ~/.newmind`

## Hub 登录失败

**症状**：无法登录 Hub

**解决方案**：
1. 验证凭据
2. 检查互联网连接
3. 尝试密码重置
4. 检查防火墙/代理

## macOS 安全

**症状**："无法打开应用"错误

**解决方案**：
1. 系统设置 → 隐私与安全性
2. 点击"仍要打开"
3. 或运行：`xattr -d com.apple.quarantine /Applications/AttackTrace.app`
