# AttackTrace 架构共识

**日期**: 2026-02-04  
**版本**: 1.0

---

## 核心架构原则

### 本地优先 + 选择性云端

AttackTrace 采用"本地优先"架构设计，在保证隐私和安全的前提下，为用户提供现代化的多设备协作体验。

---

## 数据存储策略

### 1. 完全本地存储（零信任）

**工具配置与凭证**
- **存储内容**: MCP 工具配置、密码、API 密钥、证书
- **存储位置**: 客户端本地文件系统 (`~/.attacktrace/projects/`)
- **加密方式**: 系统密钥链或客户端加密
- **云端访问**: 绝对不上传

**设计理由**:
- 工具配置包含极度敏感的凭证信息（密码、密钥）
- 符合安全行业的零信任原则和合规要求（GDPR、SOC 2、PCI DSS）
- 用户对敏感数据拥有完全控制权
- 避免云端泄露风险

### 2. 默认云端存储 + 用户可控

**会话历史与长期记忆**
- **存储内容**: 对话历史、上下文、AI 学习的项目知识
- **默认行为**: 云端加密存储
- **用户选择**: 
  - 可标记"敏感项目"为纯本地
  - 可标记单条消息不上传
  - 可开启"隐私模式"临时本地
- **数据控制**: 随时导出、删除所有云端数据

**设计理由**:
- 多设备切换是现代工作流的刚需
- 团队协作是企业版的核心价值
- 长期记忆积累是产品的差异化优势
- 会话内容敏感度相对可控（相比密码）
- 提供隐私控制满足极端安全场景

### 3. 云端服务（只读/元数据）

**保留的云端功能**
- **模型服务**: LLM API 调用、模型列表
- **工具市场**: 工具目录、版本信息、下载链接
- **用户服务**: 认证、订阅管理、额度计费
- **分析服务**: 使用统计、监控（匿名/聚合）

**不存储的内容**:
- ❌ 工具配置
- ❌ 用户密码/密钥
- ❌ 敏感项目的会话

## 架构优势

### 安全与隐私
- 符合所有主流安全标准（OWASP、PCI DSS、GDPR、ISO 27001）
- 密码永不离开客户端
- 零知识架构（对于工具配置）
- 更容易通过企业安全审计

### 用户体验
- 多设备无缝切换工作
- 团队知识共享与协作
- AI 长期记忆持续积累
- 离线工作完全可用
- 灵活的隐私控制

### 技术实现
- 降低系统复杂度（无需工具配置的同步冲突解决）
- 提升性能（本地配置访问极快）
- 减少网络依赖（除模型调用）
- 简化开发和维护

### 商业价值
- 核心价值聚焦于模型服务和工具生态
- 易于获得企业客户信任
- 清晰的分层订阅模型
- 支持未来的私有部署（Enterprise）

## 产品分层

### 标准版（个人/小团队）
- 会话默认云端存储（加密）
- 7 天历史记录
- 单条消息可标记"不上传"
- 提供导出功能
- 工具配置完全本地

### Pro 版
- 无限会话历史
- 项目级别隐私控制（整个项目可选本地）
- 细粒度敏感内容过滤
- 可选的客户端加密备份
- 团队共享会话

### Enterprise 版
- 私有部署选项（包括会话存储）
- 企业级加密和审计
- 完全气隙环境支持
- 自定义合规控制
- 专属技术支持

## 与竞品的差异化

**vs ChatGPT/Claude**:
- ✅ 工具配置本地化（更安全）
- ✅ 会话历史提供本地选项（更灵活）
- ✅ 专注安全行业场景

**vs Cursor**:
- ✅ 相似的"本地优先"理念
- ✅ 更强的隐私控制（工具配置不上云）
- ✅ 安全行业定制化

**vs Continue.dev**:
- ✅ 保留云端会话（更好的多设备体验）
- ✅ 团队协作能力
- ✅ 长期记忆积累

## 技术实现细节

### 工具市场 API（只读元数据）

**保留的 API**:
- `POST /api/v1/user/mcp/search` - 检索工具目录
- `McpServer` 表（PostgreSQL）- 存储工具元数据

**返回内容**:
```json
{
  "id": "tool-uuid",
  "name": "Elasticsearch",
  "version": "0.7.3",
  "downloadUrl": "https://github.com/.../v0.7.3/...tar.gz",
  "configSchema": { "type": "object", "properties": {...} },
  "logo": "/integrations/elasticsearch/logo-48.svg",
  "banner": "/integrations/elasticsearch/logo-240.svg",
  "description": "...",
  "document": "..."
}
```

**不包含**:
- ❌ 用户的启用状态
- ❌ 用户的配置值
- ❌ 密码/密钥

### 本地实例管理 API（按项目隔离）

**本地 API（MCP Host）**:
- `GET /api/plugins/oap-platform/instances` + `X-Project-ID` header
- `POST /api/plugins/oap-platform/instances` + `X-Project-ID` header
- `DELETE /api/plugins/oap-platform/instances/{name}` + `X-Project-ID` header
- `PATCH /api/plugins/oap-platform/instances/{name}` + `X-Project-ID` header

**数据存储**:
```
~/.attacktrace/projects/
  ├── default/
  │   ├── mcp_config.json  ← 工具配置
  │   └── db.sqlite         ← 会话历史
  ├── project-a/
  │   ├── mcp_config.json
  │   └── db.sqlite
  └── project-b/
      ├── mcp_config.json
      └── db.sqlite
```

### 会话历史中的工具记录（云端）

**会话存储** (`ChatSession.messages` in PostgreSQL):
```json
{
  "messageId": "msg-123",
  "content": "分析这个 Elasticsearch 日志",
  "toolCalls": [
    {
      "toolName": "Elasticsearch",
      "toolVersion": "0.7.3",
      "action": "search_logs",
      "timestamp": "2026-02-04...",
      "result": "找到 50 条异常..."
    }
  ]
}
```

**不存储**:
- ❌ 工具配置
- ❌ 密码/API 密钥
- ❌ 详细的连接参数

## 安全合规承诺

### 密码存储
- 采用系统密钥链（macOS Keychain / Windows Credential Manager / Linux Secret Service）
- 或客户端 AES-256-GCM 加密
- 配置文件只存储引用，不存储明文
- 符合 PCI DSS、OWASP 等标准

### 数据传输
- 所有云端通信使用 TLS 1.3
- 会话数据端到端加密（可选）
- 敏感内容自动检测和脱敏

### 数据主权
- 用户随时可以导出所有数据
- 用户随时可以删除云端数据
- 支持 GDPR 的"被遗忘权"
- 企业版支持数据驻留

## 总结

AttackTrace 通过"本地优先 + 选择性云端"的架构设计，在安全性、用户体验和商业价值之间找到了最佳平衡点：

- **安全优先**: 敏感数据绝不离开客户端
- **体验优化**: 多设备协作和知识积累
- **灵活可控**: 用户拥有完全的数据控制权
- **企业友好**: 易于通过安全审计，支持私有部署

这种架构既满足安全行业的特殊需求，又不失去现代 AI 助手的核心价值。
